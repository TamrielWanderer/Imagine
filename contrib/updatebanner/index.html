New here? Start with this

  1. Create an account on the player portal. The same page shows your characters, stats and demons later.
  2. Press Start in this launcher and log in with that account. The launcher downloads game updates by itself; let it finish first.
  3. Set your keys, extra shortcut bars and macros with KeyConfigTool.exe in the game folder. Close the game before saving.
  4. Handy chat commands: @sort sorts your inventory, @deposit stores items in the depository, @qol lists them all.
  5. Extra bars: each bar shows its own page (arrows on the bar). Drag skills and items onto them like the main bar.
  6. Please don't edit ImagineUpdate.dat: it points this launcher at the server.
